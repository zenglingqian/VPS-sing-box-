三、重装系统 Ubuntu 22.04

付款后搬瓦工会预装一个系统，但我们要换成最适合 sing-box 的 Ubuntu 22.04。

  1. 登录 KiwiVM 面板
  2. 左侧菜单滚到底 → Destructive 分组 → 点 Install New OS
  3. 系统列表选 ubuntu-22.04-x86_64
  4. 点 Reload → 确认（会清空数据，新机器无所谓）
  5. 等待 2-5 分钟，看到完成提示

重置 Root 密码

  1. 左侧菜单 → Root password modification
  2. 点 Set random root password
  3. 复制生成的新密码，保存到本地记事本

⚠️ 重要装完新系统后旧密码会失效，这一步必须做。别点左侧 Destructive 分组里的 Force Stop / Kill 按钮！

四、SSH 连接服务器

Windows 自带 PowerShell 就能连，不用装额外软件。

  1. 按 Win + X → 选 Windows PowerShell 或 终端
  2. 输入以下命令（把 IP 换成你的）：
ssh root@45.xx.xx.xx
  1. 首次连接会问 Are you sure you want to continue connecting? → 输 yes 回车
  2. 提示输密码 → 粘贴刚才保存的 root 密码 → 回车

💡 密码不显示？正常的安全机制，输入时屏幕什么都不显示，粘贴完直接回车。PowerShell 里右键鼠标或 Shift+Insert 粘贴。

成功后看到：root@localhost:~#

五、安装 sing-box

sing-box 是目前最全能的网络代理核心，原生支持 REALITY 协议。

1. 安装系统依赖

apt update && apt install -y curl

2. 用官方脚本安装

bash -c "$(curl -fsSL https://sing-box.app/)"

脚本自动完成：安装最新版 → 建配置目录 → 注册 systemd 开机自启服务。

3. 验证安装

sing-box version

看到 sing-box version 1.x.x 就成功了。

六、生成 REALITY 密钥

REALITY 协议是目前最强的反 GFW 探测方案，需要密钥对。在 SSH 终端依次执行：

1. 生成 REALITY 密钥对

sing-box generate reality-keypair

输出类似：

PrivateKey: xxxxxxxxxx
PublicKey:  yyyyyyyyyy

立刻把这两个值复制保存到本地记事本！

2. 生成 UUID（用户标识）

sing-box generate uuid

输出形如 xxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx 的字符串，保存。

3. 生成 short_id（REALITY 短 ID）

openssl rand -hex 8

输出 16 位十六进制字符串，保存。

✅ 现在你手上有 4 个值：私钥、公钥、UUID、short_id

七、写服务端配置

1. 创建配置文件

cat > /usr/local/etc/sing-box/config.json << 'EOF'
{
  "log": { "level": "info" },
  "dns": {
    "servers": [
      { "tag": "google", "address": "tls://8.8.8.8" },
      { "tag": "local", "address": "223.5.5.5", "detour": "direct" }
    ]
  },
  "inbounds": [
    {
      "type": "vless",
      "tag": "vless-reality",
      "listen": "0.0.0.0",
      "listen_port": 443,
      "users": [
        {
          "uuid": "把你的UUID粘贴到这里",
          "flow": "xtls-rprx-vision"
        }
      ],
      "tls": {
        "enabled": true,
        "protocol": "reality",
        "certificate_reload": true,
        "reality": {
          "dest": "www.microsoft.com:443",
          "server_names": ["www.microsoft.com"],
          "private_key": "把你的私钥粘贴到这里",
          "short_ids": ["把你的short_id粘贴到这里"]
        }
      }
    }
  ],
  "outbounds": [
    { "tag": "direct", "type": "direct" },
    { "tag": "block",  "type": "block" }
  ]
}
EOF

2. 替换配置中的 3 个占位符

nano /usr/local/etc/sing-box/config.json
占位符替换成
"把你的UUID粘贴到这里"你生成的 UUID
"把你的私钥粘贴到这里"reality-keypair 里的 PrivateKey
"把你的short_id粘贴到这里"openssl 生成的 16 位短 ID

改完按 Ctrl+O 保存 → Ctrl+X 退出。

3. 检查 + 启动

# 检查配置语法
sing-box check -c /usr/local/etc/sing-box/config.json

# 启动并设为开机自启
systemctl enable sing-box && systemctl start sing-box

# 查看状态
systemctl status sing-box

看到 active (running) 就是成功了。

💡 KiwiVM 面板防火墙左侧 Security → Firewall，确认 443 端口是开放状态。

八、客户端配置（Clash Verge Rev）

1. 下载 Clash Verge Rev

GitHub Releases：https://github.com/clash-verge-rev/clash-verge-rev/releases

下载 Clash.Verge_x.x.x_x64-setup.exe 安装。

2. 确认内核

打开软件 → 设置 → 内核 → 下拉选 mihomo（支持 REALITY 必须用这个）。

3. 新建配置

  1. 左侧 配置 → 右上角 新建
  2. 类型选 Local，名字随便填
  3. 粘贴下面的 YAML，替换 4 个值：
port: 7890
socks-port: 7891
mode: rule
log-level: info

proxies:
  - name: "US-GIA"
    type: vless
    server: 45.xx.xx.xx           # 你的VPS公网IP
    port: 443
    uuid: 你的UUID                  # 替换
    network: tcp
    udp: true
    tls: true
    flow: xtls-rprx-vision
    client-fingerprint: chrome
    reality-opts:
      public-key: 你的PublicKey     # reality的公钥，不是私钥！
      short-id: 你的short_id         # 替换
    servername: www.microsoft.com

proxy-groups:
  - name: "PROXY"
    type: select
    proxies:
      - "US-GIA"
      - DIRECT

rules:
  - DOMAIN-SUFFIX,google.com,PROXY
  - DOMAIN-SUFFIX,youtube.com,PROXY
  - DOMAIN-SUFFIX,netflix.com,PROXY
  - GEOIP,CN,DIRECT
  - MATCH,PROXY

4. 连接测试

  1. 配置页点一下让它变绿
  2. 左侧 代理 → PROXY 组选 US-GIA
  3. 左侧 设置 → 打开 系统代理 或 TUN 模式
  4. 浏览器访问 https://www.netflix.com 测试

✅ 成功标志Netflix 能打开并播放，speedtest.net 测速有几百 Mbps。

九、防火墙加固

1. 确认 sing-box 开机自启

systemctl is-enabled sing-box

输出 enabled 就是 OK。如果是 disabled，执行：

systemctl enable sing-box

2. 配置系统防火墙 ufw

# 先允许必要端口！
ufw allow 22/tcp
ufw allow 443/tcp

# 启用防火墙
ufw enable
# 输入 y 确认

# 验证规则
ufw status

应该看到只允许 22 和 443 端口。

⚠️ 关键！启用防火墙后，不要断开当前 SSH 窗口！新开一个 PowerShell 测试能不能重新 SSH 连上：

ssh root@45.xx.xx.xx

能连上 → 成功。连不上 → 立刻回到原窗口执行 ufw disable 回滚。

3. 可选：改 SSH 端口（防暴力破解）

# 编辑 SSH 配置
nano /etc/ssh/sshd_config
# 找到 #Port 22，改成 Port 52100（10000-65535 之间的数字）

# 放行新端口
ufw allow 52100/tcp

# 重启 SSH
systemctl restart sshd

⚠️ 改完别关当前窗口！新开窗口用 ssh -p 52100 root@45.xx.xx.xx 测试，能连上再关旧窗口。

进阶：小圈子共享方案

3-5 个朋友分摊费用，每人成本 ¥6/月，比机场便宜 5 倍。

方案 A：直接共享 UUID（零成本）

把 Clash Verge 里的 YAML 配置复制发给朋友，他们粘进自己的客户端就能用。

优点：零额外部署；缺点：共用一个 UUID，无法区分流量。

方案 B：多 UUID 独立账号

改 sing-box 服务端配置的 users 部分：

"users": [
  { "uuid": "你的UUID",   "flow": "xtls-rprx-vision" },
  { "uuid": "朋友A的UUID", "flow": "xtls-rprx-vision" },
  { "uuid": "朋友B的UUID", "flow": "xtls-rprx-vision" }
]

给每个朋友生成独立 UUID：sing-box generate uuid，然后 systemctl reload sing-box 重载配置。

方案 C：3X-UI 面板（进阶）

bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)

Web 界面管理用户、流量、到期时间。适合 5-20 人规模。

⚠️ 法律边界自己用 + 3-5 个朋友分摊 → 安全；对外收费卖节点 → 违法。

附录：代理协议知识

协议分层（对应 OSI 七层模型）

应用层   │ 浏览器/APP 想访问什么
会话层   │ 代理协议（VLESS/V2Ray/Trojan/SS）
传输层   │ 加密层（REALITY/TLS/Shadowsocks）
网络层   │ IP 路由（CN2 GIA）

主流协议对比

协议GFW 识别难度速度特点
VLESS + REALITY⭐⭐⭐⭐⭐⭐⭐⭐⭐你现在用的，最强伪装
Hysteria2⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐基于 QUIC，弱网/游戏首选
Trojan⭐⭐⭐⭐⭐⭐⭐⭐伪装成 HTTPS
Shadowsocks-2022⭐⭐⭐⭐⭐⭐⭐⭐老牌经典，速度最快

为什么需要换协议？

  • GFW 开始大规模识别某协议 → 换用新协议
  • TCP 在丢包环境下速度慢 → 换 Hysteria2（UDP+QUIC）
  • 443 端口被封 → 换其他端口或协议

💡 sing-box 一套配置支持多协议，同时开 VLESS+REALITY、Hysteria2、SS 三个入口，GFW 封了哪个就换哪个。

常见问题 FAQ

Q：IP 被封了怎么办？

KiwiVM 面板 → Network → Change IP → 一键换 IP（搬瓦工免费）。

Q：流量用完了怎么办？

KiwiVM 面板 → Services → 购买额外流量包（$1/50GB）。或者等下月重置。

Q：sing-box 挂了怎么办？

systemctl restart sing-box  # 一行搞定

Q：怎么看 VPS 用了多少流量？

KiwiVM 面板 → Network → Traffic 查看月流量统计。

Q：Netflix 显示代理错误？

可能是 IP 被 Netflix 标记了，换 IP 即可。CN2 GIA 线路被标记概率低。

Q：客户端连不上怎么办？

  1. 检查 sing-box 是否在运行：systemctl status sing-box
  2. 检查配置文件中的公钥/私钥/short_id 是否填反
  3. 检查防火墙 443 端口是否放行
  4. 检查 KiwiVM 面板防火墙

Q：怎么更新 sing-box？

bash -c "$(curl -fsSL https://sing-box.app/)"

官方脚本会检测到已安装，直接升级。
